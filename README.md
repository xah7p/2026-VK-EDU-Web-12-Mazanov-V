# TerraStack 

## Как запустить
Проект состоит из простых HTML-файлов, поднимать сервер не нужно. 
Чтобы посмотреть верстку:
1. Зайдите в папку `public/`.
2. Откройте файл `index.html` в любом браузере (можно просто перетащить файл в окно браузера).
## Страницы 
Все сверстанные страницы лежат в папке `public`:
* `base.html` — базовый шаблон (шапка, сайдбар, прибитый к низу футер).
* `index.html` — главная страница со списком вопросов и пагинацией.
* `question.html` — страница конкретного вопроса с ответами (есть лайки и отметка правильного ответа).
* `ask.html` — форма создания нового вопроса.
* `login.html` — форма авторизации (добавлен пример ошибки неправильного пароля).
* `signup.html` — регистрация (с блоком загрузки аватарки и примером ошибки валидации email).
* `profile.html` — страница настроек профиля.
## Детали реализации
* Для сетки и стилей использован **Bootstrap**. Все CSS и JS файлы скачаны и лежат локально в `public/static/`, CDN не используется.
* Сделан минимальный адаптив: на мобилках шапка сворачивается в бургер, а правая колонка уходит вниз, чтобы не было горизонтального скролла.
* Картинки для заглушек также лежат в `public/static/img/`.
